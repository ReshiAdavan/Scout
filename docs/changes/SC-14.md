# CLI contract

Scout now performs one search by default; use --watch to retain the previous daemon behavior. --keywords selects the keyword file, --threads limits concurrent file jobs (1–256), --poll-ms controls polling, --extension can be repeated, and --color accepts auto/always/never. -- separates options from a root beginning with a hyphen.

Exit statuses are 0 for matches, 1 for no matches, and 2 for errors. Watch mode exits 0 on SIGINT/SIGTERM. Results are sorted by file, byte offset and keyword; diagnostics go to stderr. Worker errors propagate to main instead of terminating a thread. Files changing during a scan produce an explicit retry error and are not cached as successful.

The session stores even empty match sets, reconciles deleted files, and invalidates results when keywords change. It fingerprints content each round; cached results avoid matching work, not all filesystem reads. The root's .scoutignore is used (rather than the launch directory's).
