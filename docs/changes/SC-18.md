# Named search profiles

Use --config scout.conf --profile migration. Config is a versioned line format with whitespace-separated fields; double-quoted fields support spaces, quotes and backslashes through C++ quoted-string escaping. Example:

```
version 1
profile migration
root "src"
extension ".cpp"
ignore-case false
whole-word true
match-mode "all"
keyword "old-client" "migration" "OldClient"
keyword "old-call" "deprecated-api" "old_call"
```

Profiles may contain root, extension (repeatable), ignore-case, whole-word, match-mode and keyword records. Root paths are relative to the configuration file. Explicit CLI options override corresponding profile settings; --keywords overrides profile keyword records. Unknown fields/profiles and duplicate keyword IDs are errors. Watch mode reloads the config each round.

A keyword record is ID, tag, literal. Different IDs can share a literal and each receives a labeled result after overlap selection. JSON/JSONL/CSV export IDs and tags; plain keyword files use the literal as the implicit ID. Keyword IDs do not replace literal pattern identities in the matcher.
