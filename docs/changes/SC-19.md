# File queries and statistics

Repeat --require-all ID to require every listed ID in a file, or --require-any ID to require at least one. These modes are mutually exclusive. IDs come from the selected profile, or literal keywords for a plain keyword file. Unknown IDs are errors; duplicate query IDs do not multiply results. Conditions are evaluated after case, whole-word and overlap selection. All selected matches from accepted files are emitted, including other configured IDs.

--stats writes a JSON statistics record to stderr, leaving stdout in the requested result format. Counts describe emitted labeled occurrences, not raw matcher candidates. Two labels on the same literal therefore count as two occurrences. Reports include matching files, counts per file/ID (including zero-result IDs), scan bytes, scanned files, cache hits and elapsed time. Fingerprinting I/O is not included in scannedBytes, which measures files sent to the matcher.
