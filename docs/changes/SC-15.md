# Structured results

--format supports text, editor, json, jsonl and csv. JSON returns one object with a matches array; CSV always emits a header; JSON Lines emits one object per match. Watch mode supports text, editor or jsonl to avoid concatenating whole JSON documents or CSV headers.

byteOffset is zero-based; line and column are one-based, and column counts bytes. CRLF is one line break. Match text preserves original bytes. Valid UTF-8 is preserved in JSON; invalid bytes are escaped as U+00XX, so consumers needing byte-for-byte reconstruction should use offsets against the original file. Machine formats never emit ANSI codes. Editor format is intended for textual single-line keywords.

Coordinates are computed from the file snapshot and verified against the content fingerprint before insertion into the cache. This currently reads each changed file into memory for coordinates; bounded indexing does not imply bounded per-file scanning memory.
