# Incremental index and watch deltas

--watch now emits only added/removed selected results, with an initial added event for each result. JSONL uses {event,match}; text/editor prefix + or -. Unchanged rounds are quiet unless --stats is explicitly enabled. Identity includes exported fields, so context/label changes produce remove/add. Polling coalesces changes between rounds; --poll-ms controls the interval.

--cache FILE enables a versioned, atomically replaced snapshot containing fingerprints and complete canonical results. Root, pattern order, case and whole-word settings identify the snapshot; mode/labels/query predicates remain read-time views. Missing, malformed, oversized or incompatible snapshots are cache misses. Legacy unsafe binary serialization is removed. Cache writes use unique same-directory temporary files and rename; this provides atomic replacement, not a power-loss durability guarantee. Content fingerprints are still verified for warm starts. Concurrent writers may replace each other's snapshots, but query identity prevents incorrect reuse.

--index-mb N (default 64) bounds estimated retained match payload. Entries are evicted deterministically in path order after a round and rescanned on demand; results are never silently truncated. Statistics expose retainedIndexBytes and evictedFiles. This is not a total RSS limit: current results, file snapshots, hash-map/container overhead and worker allocations are additional memory. Snapshot files above 128 MiB are ignored on load. Watch currently keeps the prior emitted result set for diffing.

The final validation PR adds retry handling for files disappearing/changing during a watch scan: incomplete rounds publish no deltas, and the next poll retries. One-shot searches still report the error.
