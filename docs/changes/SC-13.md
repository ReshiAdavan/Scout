# Traversal and fingerprints

Traversal applies scoped nested .gitignore files and root .scoutignore exclusions, prunes ignored directories, skips symbolic links, and excludes .git, .cache and .match_index. Supported patterns include *, **, ?, bracket classes, leading slash, directory suffix, ordered negation, escaped leading markers, and spaces. An ignored parent directory must be re-included before rules inside it can apply. .scoutignore acts as a separate exclusion layer; it does not re-include .gitignore exclusions. Git global excludes and .git/info/exclude are not consulted. Traversal errors are reported rather than silently returning incomplete results.

The cache now uses a stable 64-bit FNV-1a content fingerprint rather than timestamps. This detects same-size edits with restored timestamps, at the cost of reading content when checking for changes. It is a noncryptographic change detector, not an integrity guarantee. Unsafe legacy binary cache APIs are removed; coherent persistent results are handled separately.
