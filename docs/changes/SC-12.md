# Watch lifecycle correctness

Watch sessions compare the entire keyword list and rebuild a fresh automaton when it changes. Each inventory removes deleted files from the result index. Interrupt handling writes only a sig_atomic_t flag; ordinary code performs shutdown.

Legacy persistent caches do not identify the root/query or validate their binary payload. The CLI therefore starts with fresh session state and no longer reads or writes them. This deliberately trades cross-process warm starts for correctness; in-process reuse remains available. A future versioned persistence change must validate input and atomically save a coherent snapshot before re-enabling disk reuse. Existing cache files are preserved.
