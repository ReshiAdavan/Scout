# Editor ranges

--format lsp emits a JSON array of Location-shaped objects with percent-encoded absolute file URIs, zero-based lines, UTF-16 character offsets, and exclusive ends. LF, CRLF and lone CR are line endings. Astral characters count as two UTF-16 units. Match endpoints must lie on valid UTF-8 boundaries; invalid ranges fail before output is written. Ordinary byte-oriented search/export remains available for other encodings.

This is a batch output adapter, not a JSON-RPC language server. It is intended for editor extensions consuming search results. Watch mode uses JSONL events rather than a stream of LSP arrays. Range metadata is saved in version 3 snapshots; older snapshots safely rebuild.

Semantics follow Microsoft's LSP Position/Range definitions: https://github.com/Microsoft/language-server-protocol/blob/gh-pages/_specifications/specification-3-14.md
