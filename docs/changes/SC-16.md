# Case and word semantics

--ignore-case folds ASCII A–Z only, preserving byte offsets and original matched text. Non-ASCII bytes remain case-sensitive. --whole-word requires both neighboring bytes to be outside ASCII letters, digits and underscore. The file snapshot supplies neighbors even across read/slice boundaries. These are deliberately byte-oriented semantics, not Unicode linguistic word segmentation.

Changing either option invalidates session matches. Distinct configured patterns retain their original identities even if they fold to the same literal.
